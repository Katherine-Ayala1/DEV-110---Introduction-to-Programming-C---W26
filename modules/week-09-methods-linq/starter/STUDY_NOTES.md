## Methods and Decomposition

**Why is it helpful to break a program into small methods?**
Answer:Breaking a program into smaller methods makes the code easier to read and understand, since each method has a specific task; it helps keep the program organized. Having a program organized also helps with debugging since you can focus on one section rather than having everything all over the place.

## LINQ (Stats + Method Chaining)

**Which LINQ methods did you use for basic statistics?**
Answer:The LINQ methods used for basic statistics were Min(), Max(), Average(), and count().

**Which LINQ methods did you chain together for reports?**
Answer:Some LINQ methods that are chained together si Where() with OrderByDescending() to filter and sort scores, and OrderByDescending() with Take() to get the best scores.

**Why is it helpful to put score logic in a class (ScoreReport) instead of keeping everything in Program?**
Answer:Putting the score logic in a class like scoreReport keeps the program more organized (looks cleaner) and easier to maintain.
